# CPing v1.1.1 —— GUI 布局修正

这是一个**补丁版本**，只改界面布局，不改探测、分类、导出、快照的任何行为。
如果你用的是 v1.0.0 / v1.1.0 的界面，装上这个版本就不必再拖着滚动条找内容了。

## 修了什么

**表格横向滚动条**（影响最大）
「表单显示」七列（IP / 状态 / RTT / MAC / 厂商 / 主机名 / 类别）的固定宽度
合计约 1050px，而主区只有约 690px——表格必然被撑宽、产生横向滚动条，
右侧的**厂商和主机名列基本等于看不见**。

现在改用固定表格布局 + 按比例的列宽：列永远填满容器宽度，放不下的内容
就地省略号截断，鼠标悬停可看完整值。横向滚动条消失。

**侧栏纵向滚动条**
默认 1000×680 时侧栏内容约 694px、可用高度只有约 614px，必然出现纵向
滚动条，最下面的「已识别 MAC / 厂商 / 主机名」被压在可视区之外。

初始窗口放大到 **1240×840**，同时收紧侧栏间距；屏幕高度不足时还有一层
媒体查询进一步压缩，把「需要滚动」尽量往后推。

**顺带的健壮性**
启动时按当前显示器的可用区域（已扣除任务栏）检查窗口尺寸，**只缩小不放大**：
在 1366×768 这类屏幕上不会再出现窗口顶出屏幕、标题栏拖不回来的情况。
显示器足够大时行为完全由配置决定，不会出现启动瞬间的跳变。

## 验证

- 用 `PrintWindow` 抓取窗口自身内容逐项核对：空态侧栏无滚动条、256 格矩阵
  完整放下、表格七列全部在一屏内
- `cargo fmt --check` / `cargo clippy -D warnings`（workspace 与 GUI 两套）/
  `vue-tsc` 全部干净；`cargo test --workspace` 151 个测试全绿
- 本版未改动核心逻辑，测试计数与 v1.1.0 相同
